# Руководство по PixPlant

## 1. Общие сведения

### 1.1 Общие принципы работы

Для создания карты одного цвета или интенсивности нажмите кнопку New Map (Новая карта), которая является первой кнопкой над областью Редактора.

В окне New Map (Новая карта) слева можно выбрать размер новой карты. Кнопка в виде замка фиксирует пропорции между шириной и высотой.

С правой стороны окна можно выбрать, какие карты создать, и задать их начальные значения.

Установите флажок напротив названий карт, которые необходимо создать. По умолчанию отмечен только текущий активный тип карты, но можно нажать Select All (Выбрать все), чтобы отметить все карты.

Рядом с отмеченным названием карты можно задать начальный цвет или интенсивность для новой карты (новых карт).

Наконец, нажмите Create (Создать) для инициализации новых карт. Проверьте результат в окне 3D Preview (3D-предпросмотр), где отобразится рендер новых карт.

Другой способ создания карты — извлечение её из изображения или другой карты. Например, рассмотрим, как извлечь карту смещения (Displacement map) из карты базового цвета (Base Color map).

Начните с открытия изображения в редакторе Base Color. После открытия изображения в редакторе Base Color переключитесь на редактор Displacement.

Выберите инструмент Extract (Извлечь) в верхней части области Map Tools (Инструменты для карт).

Подсказка: инструменты, расположенные выше разделительной линии, предназначены для извлечения или импорта новых карт, тогда как инструменты ниже будут доступны только при открытой карте. В переключателе Method (Метод) выберите From Shading (По затенению), так как извлечение будет выполняться на основе информации о затенении в карте Base Color.

В настройке Source (Источник) выберите Base Color Map (Карта базового цвета).

Начнётся процесс извлечения, и будет создана карта смещения, параметры которой можно настроить с помощью появившихся настроек в инструменте Extract.

Переключайтесь между 3D- и 2D-видами карты, нажимая кнопку в левом верхнем углу области Редактора.

Масштабируйте карту смещения вращением колёсика мыши. Также можно перетаскивать изображение, удерживая правую кнопку мыши, для вращения. Удерживая среднюю кнопку мыши, можно перемещать карту смещения по экрану.

Возможно, потребуется использовать настройки в инструменте Extract для точной настройки извлечения: подробнее см. руководство "Извлечение карты смещения" в разделе руководств по Displacement.

Следующий видеоурок охватывает ввод/вывод карт:
Opening, Creating and Saving 3D Maps

### 1.2 Экспорт карт

(Пожалуйста, максимально расширьте окно руководства по вертикали, так как следующий шаг содержит много текста и, к сожалению, не имеет прокрутки.)

Начнём с создания нескольких карт для экспорта. Нажмите кнопку New Map (Новая карта), которая является первой кнопкой слева над областью Редактора.

С правой стороны окна New Map, в нижней части, нажмите Select All (Выбрать все), чтобы отметить все типы карт для создания.

Теперь снимите флажки с карт Displacement и Opacity, чтобы позже увидеть одну из возможностей окна экспорта.

Наконец, нажмите Create (Создать) для инициализации новых карт. Над областью Редактора, между кнопками Save As (Сохранить как) и Close (Закрыть), вы найдёте кнопку Export Maps (Экспортировать карты): нажмите её, чтобы открыть окно экспорта.

В верхней части открывшегося окна можно выбрать используемый пресет в выпадающем меню Preset: выберите "Unreal".

Под описанием пресета в строках Output Maps перечислены все карты, которые будут экспортированы данным пресетом. Любую из этих выходных карт можно снять с отметки, если она не требуется.

Наведите курсор на текстовое поле имени файла в первой строке. Появится подсказка, показывающая каналы и источники, которые будут использованы для создания этого вывода.

Вы должны увидеть примерно следующее:

Channels:
RGB=Base Color map:
A=1.0 (default)

Это означает, что каналы RGB данного вывода берутся из карты Base Color. Канал A (альфа) установлен на значение по умолчанию 1.0 — обычно он берётся из карты Opacity, но поскольку мы не создали её на предыдущем шаге, используется значение по умолчанию.

Наведите курсор на имя файла во второй строке вывода (с именем _OcclusionRoughnessMetallic): подсказка покажет задействованные каналы и их исходные карты.

Обратите внимание на третью строку, выводящую карту _Height: она автоматически снята с отметки, так как зависит от карты Displacement, которую мы не создали на предыдущем шаге.

В каждой строке рядом с именами выходных файлов расположены выпадающие меню Formats и Bits, где можно выбрать формат файла и точность в битах. Выходные файлы с каналами RGB и альфа могут быть типа PNG или TIFF, тогда как файлы только с RGB или в оттенках серого могут быть в форматах EXR, JPEG, PNG или TIFF.

Теперь введите префикс имени, который будет использоваться при создании имён экспортируемых файлов: это делается в текстовом поле Base Name. По мере ввода имена файлов выше будут обновляться до своих финальных значений.

Далее выберите местоположение, куда будут записаны файлы: это делается в настройке Folder.

Наконец, нажмите Export. Выходные карты будут упакованы и сохранены, готовые к использованию в Unreal Engine (выбранный выше пресет).

### 1.3 Область 3D-предпросмотра

С левой стороны окна PixPlant расположена область 3D Preview (3D-предпросмотр), которая отображает редактируемые карты с использованием физически корректного рендеринга (PBR) или алгоритма Blinn-Phong для традиционного рабочего процесса, оба с поддержкой параллакса или карт смещения.

В верхней части можно выбрать, какие открытые 3D-карты будут отображаться. Можно нажать кнопку справа, чтобы открепить 3D Preview в плавающее окно.

Нижняя панель управляет несколькими аспектами 3D-рендеринга: 3D-модель, выбранная HDRI-карта окружения для PBR или включённый источник света.

Попробуйте нажать кнопку Undock (Открепить) в правом верхнем углу 3D Preview. Окно 3D Preview отделится от основного окна PixPlant и может быть размещено на втором дисплее, если таковой имеется.

Заметили кнопку ( i ) в левом нижнем углу окна просмотра? Можно нажать на неё, чтобы получить дополнительную информацию о просмотрщике и его элементах управления.

Чтобы снова закрепить 3D Preview, нажмите кнопку закрытия окна. Вернувшись в основное окно PixPlant, в центре вы найдёте область Редактора, где можно редактировать карты различных типов.

Над областью Редактора расположены вкладки с названиями типов карт для текущего 3D-рабочего процесса: нажатие на одну из этих вкладок выбирает тип карты, который редактируется.

Нажмите другую вкладку, чтобы выбрать иной тип карты. Если при переключении типа карты мало что изменилось, это связано с тем, что в Редакторе не открыта ни одна карта — редакторы довольно скучны, когда в них ничего не редактируется!

Кнопки над редактором выполняют общие операции: New/Open/Save/Close (Создать/Открыть/Сохранить/Закрыть), Undo/Redo (Отменить/Повторить), функции Copy+Paste (Копировать+Вставить), а также External Edit (Внешнее редактирование) и кнопка Feedback (Обратная связь).

Помимо использования этих кнопок для создания/открытия/вставки файла, можно перетащить один или несколько файлов (или даже папку) в область Редактора, и они будут открыты в соответствующих редакторах через диалог Open Maps.

Попробуйте перетащить файл и отпустить его в области Редактора. Карта теперь открыта в редакторе. Её можно масштабировать и перемещать, а также изменять с помощью текущего инструмента Map Tool: см. кнопку информации ( i ) Редактора для получения справки.

Обратите внимание на небольшую панель, появляющуюся под областью Редактора: она содержит информацию о текущей открытой карте и другие настройки, такие как переключатель Tiling Preview, который повторяет изображение по краям для лучшей визуализации его тайлинга.

Но как её редактировать? С помощью Map Tools (Инструменты для карт). Инструменты Map Tools расположены с правой стороны окна PixPlant. Каждый тип карты имеет свои инструменты (хотя многие схожи между типами), которые можно использовать для редактирования карты (или даже нескольких карт одновременно).

Вы заметите разделитель светло-серого цвета, разделяющий названия инструментов. Любые инструменты выше этого разделителя можно использовать для создания/извлечения/проверки карты, поэтому им не требуется открытая карта, и они всегда доступны. Однако инструменты ниже разделителя требуют открытой карты для работы (и отключены, если карта в данный момент не открыта).

Попробуем инструмент: нажмите инструмент Paint (Кисть), заголовок которого расположен примерно посередине Map Tools.

Инструмент Paint откроется с несколькими настройками, управляющими такими параметрами, как размер и жёсткость кисти. Попробуйте рисовать в области Редактора.

Чтобы получить информацию об инструменте и значении доступных настроек, откройте его и подержите курсор мыши над его заголовком: появится кнопка ( i ), на которую можно нажать для получения справки.

Теперь нажмите инструмент Adjust (Коррекция), расположенный на несколько позиций выше инструмента Paint. Все ползунки можно управлять колёсиком мыши: попробуйте вращать колёсико, когда курсор находится над ползунком. Также можно сбросить большинство ползунков к базовому значению, нажав на их названия или значения, расположенные по краям. Ещё один приём с ползунками: удерживая Ctrl при вращении колёсика над ползунком, можно изменять его значение меньшими шагами для более тонкой настройки.

В правом верхнем углу основного окна PixPlant вы найдёте три большие кнопки:

- Extract 3D Maps: извлечение карт из изображения, открытого в редакторе Base Color.
- Guides: руководства, которые вы уже знаете, так как сейчас просматриваете это руководство.
- Global Settings: изменение 3D-рабочего процесса или глобального режима тайлинга. Режим тайлинга определяет, должны ли карты зацикливаться по горизонтали, вертикали или в обоих направлениях (по умолчанию). Эта настройка влияет на поведение инструментов карт, таких как Tiling Synth, Offset и Paint. Например: рисование вдоль краёв карты будет зацикливаться на противоположную сторону только если текущий режим тайлинга это позволяет.

Нажмите любую из этих кнопок, чтобы увидеть появляющиеся опции. Попробуйте создать несколько карт, нажав кнопку New Maps в верхней части области Редактора, и ознакомьтесь с доступными инструментами для каждой карты.

Помните, что для контекстной справки всегда можно нажать ближайшую кнопку ( i ). Или найдите руководство, описывающее то, что вы пытаетесь сделать.

Надеемся, вы отлично проведёте время с PixPlant! Следующие видеоуроки демонстрируют некоторые аспекты пользовательского интерфейса PixPlant:
- User Interface Tour
- 3D Preview
- Environment and Autorotation

Пожалуйста, смотрите в полноэкранном режиме, нажав кнопку в правом нижнем углу просмотрщика.

### 1.4 Информация о физическом размере

Это руководство показывает, как добавлять и изменять информацию о физическом размере в 3D-картах.

Физический размер работает путём установки значения DPI, которое вместе с шириной и высотой карты в пикселях позволяет хранить реальный физический размер.

DPI означает Dots Per Inch (точек на дюйм) — в нашем случае точками являются пиксели, поэтому фактически это означает пикселей на дюйм. Например, предположим, у вас есть карта размером 1024 × 1024 пикселя: если установить для этой карты значение DPI 1024, она будет занимать один дюйм реального физического размера. Устанавливая информацию о DPI, мы указываем, что эти 1024 пикселя поместятся в пространстве одного дюйма (или 2,54 сантиметра). Таким образом, мы можем хранить информацию о реальном размере в наших картах.

Поскольку физический размер зависит от информации о DPI, он работает только с форматами изображений, способными хранить эти данные: PNG, TIFF, JPEG, BMP.

Вы увидите размеры, отображаемые в сантиметрах (см) или дюймах ("). Это можно изменить в окне Preferences (Настройки). Проверьте область сразу под Редактором, с его левой стороны: вы найдёте информацию о физическом размере, которую вы ранее выбрали, рядом с размером в пикселях.

Если ширина и высота в пикселях равны, вы увидите только одно значение, например "30,0 см", которое является размером стороны. Но если карта имеет разные значения ширины и высоты в пикселях, будут отображены два значения.

Аналогично, при открытии файла в форматах, хранящих информацию о DPI (PNG, TIFF, JPEG, BMP), вы также найдёте информацию о его физическом размере, указанную в этой области. Изменить информацию о физическом размере можно в инструменте Transform, в нижней части области Map Tools.

Элементы управления точно такие же, как мы видели в окне New Map, они расположены в области Final Size. Установите поле DPI на соответствующее значение, но по возможности избегайте изменения размеров в пикселях, так как это приведёт к передискретизации изображения.

Используя этот инструмент, можно применять или корректировать информацию о физическом размере/значениях DPI в любых картах, включая созданные в сторонних приложениях.

### 1.5 Физически корректный рендеринг (PBR)

Идея, лежащая в основе физически корректного рендеринга (PBR), заключается в использовании реалистичных моделей затенения/освещения для точного представления материалов реального мира. Для этого карты PBR хранят информацию о том, как поверхность реального мира реагирует на законы физики, в частности на взаимодействие со светом. Будучи близким приближением к законам физики, PBR является максимально реалистичным.

Помимо реализма, PBR имеет ещё одно важное преимущество перед предыдущими 3D-рабочими процессами: он согласован при различном освещении, что позволяет повторно использовать материалы в разных сценах и условиях освещения, что ранее было невозможно.

Чтобы увидеть, как каждая карта вносит вклад в PBR, нажмите кнопку New Maps, расположенную над областью Редактора.

В появившемся окне New Maps нажмите Select All, чтобы создать все карты. На самом деле для PBR нам понадобятся только Base Color, Metallic и Roughness, но создание остальных карт не повредит.

Выберем пресет, определяющий начальные значения карт: в выпадающем меню Presets... в правом верхнем углу выберите пресет Gold, расположенный в верхней части списка.

Нажмите Create, и будет создан физически точный материал золота. Повращайте модель в 3D Preview, чтобы увидеть, как она отражает окружение.

В физической реальности свет, падающий на поверхность, разделяется на две части:

- Отражение: часть входящего света отражается от поверхности, отскакивая, как мяч от стены. Отражение придаёт поверхностям блеск или спекулярность. Например, зеркало — это крайний случай отражения: весь свет отражается.
- Диффузия: другая часть входящего света поглощается и рассеивается в поверхности, при этом часть впоследствии выходит наружу. Именно этот вышедший свет придаёт поверхностям их цвет.

Поскольку PBR моделирует поведение реального света, энергия, входящая в объект, должна быть равна сумме частей отражения и диффузии, чтобы сохранялась общая энергия, иначе законы физики были бы нарушены. Из-за этого поверхности с высоким отражением обычно не имеют сильного цвета (как зеркало). С другой стороны, поверхность яркого цвета не может быть сильно отражающей.

Кстати, идея, связанная с отражением, — это эффект Френеля: поверхность отражает больше, когда вы смотрите на неё под малым углом (скользящим), чем когда смотрите прямо (под углом 90 градусов). Вы можете проверить это на многих поверхностях реального мира: при взгляде под малым углом они становятся более отражающими, некоторые почти как зеркало. Эффект Френеля автоматически обрабатывается PBR, чтобы сохранить максимальную реалистичность.

В рабочем процессе PBR Metallic-Roughness, который мы используем, карта Base Color определяет как отражённый, так и диффузный свет, выходящий из поверхности. Выбранный нами пресет золота установил для этой карты жёлтый цвет, но что это означает? Проверьте следующий шаг, чтобы увидеть, как это работает.

Металлические участки поверхности обычно более отражающие, чем немаксимальные. Мы будем называть эти немаксимальные участки диэлектриками. Это полезное свойство лежит в основе рабочего процесса Metallic-Roughness — наиболее широко используемой модели PBR.

Если мы можем указать, какие части поверхности ведут себя как металл или как диэлектрик, мы можем затем использовать карту Base Color для указания:

- Оттенка отражения для металлических участков: например, жёлтый оттенок золота.
- Диффузного цвета для диэлектрических участков: например, красный цвет в яблоке.

Именно для этого используется карта Metallic: металлические пиксели помечаются значением 1 (белый), диэлектрические — значением 0 (чёрный). Таким образом, PBR знает, следует ли обрабатывать эти пиксели как металлические и оттенять отражение света, или как диэлектрические, окрашивая их диффузный свет.

В основном используются только значения 1 и 0, поскольку пиксель может быть либо металлическим, либо диэлектрическим. На практике другие значения могут использоваться для создания поверхностей, таких как ржавчина или тонкий слой грязи.

Чтобы увидеть это в действии, выберите инструмент Paint Tool справа. Выберите его операцию Paint и установите ползунок Metallicness на 0 (означает диэлектрик) и Hardness на 100% (без сглаживания кисти, чтобы избежать размытых промежуточных значений). Нанесите несколько мазков в нижней части карты Metallic, нажав левой кнопкой мыши в Редакторе и перетащив.

Вы заметите, что зеркальные характеристики золота исчезли, и окрашенная область ведёт себя больше как пластик: теперь больше света диффундирует, отсюда и сильный цвет, и мало света отражается, поэтому вы больше не видите отражения окружения.

Также очень важно для моделирования реалистичных поверхностей их поведение на очень малом масштабе, что сильно влияет на отражение и диффузию света. Шероховатость, крошечные несовершенства и трещины на поверхности естественным образом оказывают сильное влияние на входящий свет.

Если поверхность гладкая, входящие лучи света отражаются параллельно друг другу, так же как зеркало отражает когерентным образом. Но если поверхность шероховатая, лучи будут отражаться хаотичным образом, и видимый результат будет представлять собой размытое отражение, поскольку лучи света будут отскакивать в случайных направлениях, редко параллельно друг другу.

Для моделирования этого поведения микроскопической поверхности мы используем карту Roughness: пиксели со значением 1 (белый) являются шероховатыми, со значением 0 (чёрный) — гладкими.

Посмотрим это в действии: откройте инструмент Adjust и медленно увеличьте ползунок Intensity вправо, обращая внимание на отражения в модели в 3D Preview. Отражения становятся размытыми по мере увеличения шероховатости поверхности. В то же время область, которую мы покрасили как диэлектрик, мало меняется: будучи диэлектриком, она не отражает много света напрямую.

Поиграйте с ползунком Intensity и повращайте 3D-модель. Из-за сохранения энергии вы заметите, что более шероховатые поверхности (шероховатость близка к 1 или белому) отражают свет с более крупными, но более тусклыми бликами, так как свет отскакивает во всех направлениях, тогда как гладкие поверхности (шероховатость близка к 0 или чёрному) имеют меньшие и более резкие блики, поскольку свет отскакивает более когерентным образом.

Прежде чем продолжить, пожалуйста, установите ползунок intensity обратно на 0%. Простой способ сделать это — нажать на метку "Intensity", что сбросит настройку.

Вернувшись в редактор Base Color, посмотрим, как информация о его цвете используется металлическими или диэлектрическими пикселями, которые мы установили ранее в карте Metallic. Помните, что карта Metallic определяет, как используются пиксели Base Color: либо для оттенения металлических отражений, либо для определения диффузных цветов диэлектриков.

Выберите инструмент Paint и выберите его операцию Paint. В палитре Color picker выберите яркий беловато-голубой цвет. Теперь нанесите несколько вертикальных мазков сверху вниз.

Повращайте модель в 3D Preview, чтобы увидеть, как она отражает окружение.

В мазках, нанесённых в верхней части, где пиксели были установлены как металлические в карте Metallic, синий цвет просто оттеняет отражение окружения.

Но мазки в нижней части, нанесённые поверх окрашенного диэлектрика, выглядят скорее как сплошной цвет с малым отражением.

Для полного соблюдения технических ограничений PBR следует учитывать несколько правил. Например, металлические участки всегда должны иметь яркие значения цвета из-за их высокой отражательной способности, тогда как диэлектрические участки должны избегать чрезмерной яркости. Настройка PBR Validate доступна в нижней части редакторов Base Color и Metallic, которая отображает красно-зелёное наложение для недопустимых/допустимых значений, помогая выявить любые проблемы. Чтобы узнать больше об этом, см. руководство PBR Validate.

### 1.6 Сохранение карт

Это руководство содержит информацию о сохранении одной или нескольких карт.

Начните с нажатия кнопки New Map в верхней части Редактора, чтобы у нас была карта для сохранения.

Появится окно New Map с выбранным текущим типом карты: нажмите кнопку Create. Теперь, когда карта создана, обратите внимание, что рядом с заголовком вкладки Редактора появляется знак *, например "Base Color*", что означает, что карта имеет несохранённые изменения.

Сохраните карту, нажав кнопку Save Map или "Save Map As" в верхней части.

Появится окно Save Map с отмеченным для сохранения текущим типом карты. Нажмите на текстовую область Filename или кнопку [...] рядом с ней, и откроется стандартное окно сохранения файла. В этом окне есть две важные опции, которые необходимо выбрать:

- Фактический путь и имя файла, под которым должна быть сохранена карта.
- Format и Precision Bits, которые можно выбрать в поле "Save as type". Нажмите на него, чтобы увидеть доступные форматы.

После выбора пути карты и формата/точности нажмите Save, чтобы вернуться в предыдущее окно. Затем снова нажмите Save, чтобы фактически сохранить карту.

Теперь, когда карта сохранена, знак *, который ранее отображался рядом с заголовком вкладки Редактора, исчез, что означает отсутствие несохранённых изменений.

Теперь посмотрим, как сохранить несколько карт. Для создания этих карт снова нажмите кнопку New Maps в верхней части.

На этот раз нажмите ссылку Select All, появившуюся в нижней части, которая выберет для создания все типы карт из текущего 3D-рабочего процесса.

Нажмите кнопку Create для продолжения. Как и ранее, новые карты появляются со знаками * рядом с заголовками их вкладок, так как все они ещё не сохранены.

Чтобы сохранить их, нажмите одну из кнопок Save Map или "Save Map As" в верхней части.

На этот раз окно Save Maps отображает все открытые карты. Но вручную выбирать все имена файлов и пути по одному могло бы занять много времени...

К счастью, у нас есть функция "Set Automatic Filenames" для помощи. Эта функция создаёт имена файлов для карт на основе выбранной папки, базового имени и автоматических суффиксов, которые можно определить в окне Preferences. Итак, нажмите переключатель "Set Automatic Filenames" в нижней части, и появятся новые поля:

- Base Name — префикс, с которого будут начинаться все имена файлов.
- Folder — фактический каталог, в который будут сохранены файлы.
- Format и Precision Bits выбирают формат файла изображения и используемые биты точности.

Попробуйте ввести текст в поле Base Name: имена файлов выше обновляются до своих финальных форм по мере ввода.

Нажмите кнопку Save для сохранения всех карт. Все файлы были сохранены, и знаки * несохранённых изменений в заголовках вкладок исчезли, что означает отсутствие оставшихся несохранённых изменений.

### 1.7 Бесшовный тайлинг

Инструмент Tiling Synth создаёт бесшовно повторяющуюся версию изображения, анализируя его особенности и лежащий в основе паттерн.

Начните с выбора типа карты, который вы хотите зациклить, выбрав его редактор на вкладках над областью Редактора.

Если вы хотите создать тайлинг из обычного фото, можно использовать редактор Base Color, так как он поддерживает входы sRGB. После выбора редактора откройте изображение, которое вы хотите зациклить.

Выберите инструмент Tiling Synth в нижней части области Map Tools.

Нажмите на выпадающее меню Seed Image и выберите "Use Current Map".

Это будет использовать текущую карту как исходное изображение для генерации её повторяющейся версии. Нажмите кнопку Generate в нижней части инструмента Tiling Synth.

Начнётся генерация, и через некоторое время повторяющаяся версия исходной карты будет готова.

Вы можете лучше увидеть тайлинг по краям изображения, если включите переключатель Tiling Preview в нижней части.

Если сгенерированное изображение вас не устраивает, попробуйте нажать Generate ещё раз, так как каждое синтезированное изображение уникально. Однако если текстура всё ещё не зацикливается правильно, возможно, потребуется помочь PixPlant. Для этого предназначен Seed Wizard: нажмите кнопку с этой меткой, чтобы открыть его.

Окно Seed Wizard — это место, где вы помогаете PixPlant создать лучший тайлинг исходного изображения. Это делается в два шага: выпрямление изображения и определение его паттерна (если таковой имеется).

На первом шаге мастера вы должны переместить четыре маркера слева так, чтобы отображаемое изображение справа было выпрямлено, то есть максимально выровнено по сторонам изображения.

Нажав Next, Seed Wizard перейдёт к шагу выбора паттерна. Если элементы изображения образуют паттерн, вам нужно будет помочь PixPlant понять его сетку. Например, если исходное изображение — это фото кирпичной стены, паттерном будет группа кирпичей, повторяющихся по изображению. Однако если изображение не имеет наблюдаемого паттерна, просто нажмите No Pattern в нижней части.

Нажмите Finish, чтобы вернуться к инструменту Tiling Synth.

Нажмите кнопку Generate, и PixPlant теперь должен быть способен генерировать лучшие результаты. Если вы хотите сгенерировать без включения части исходного изображения, нажмите в Seed Viewer (просмотрщик над кнопкой Seed Wizard), чтобы исключить один или несколько прямоугольников, которые не будут использоваться для генерации. Следите за тем, чтобы осталось достаточно областей для работы PixPlant.

После исключения нажмите кнопку Generate, чтобы увидеть результаты.

### 1.8 Открытие файлов карт

Рассмотрим несколько различных способов открытия файлов карт.

Начните с выбора редактора карт того типа, который вы хотите открыть, на вкладках над областью Редактора. Откройте карту, нажав кнопку Open, которая является второй кнопкой над областью Редактора.

Появится окно Open File: выберите файл и нажмите Open. Более простой способ открыть файл — просто перетащить его из Проводника Windows и отпустить в области Редактора.

Если редактор карт того типа, который вы хотите открыть, не является текущим активным типом, наведите перетаскиваемый значок файла над вкладками типов карт: активный редактор изменится, и вы сможете отпустить файл в область Редактора (не на саму вкладку).

Когда значок файла будет отпущен в области Редактора, он откроется и станет доступным для редактирования. Чтобы открыть несколько карт одновременно, чтобы можно было открыть полный материал, можно либо выбрать несколько файлов в окне Open Maps, которое мы видели в шаге 2 этого руководства, либо просто перетащить файлы в текущее окно Редактора.

В любом случае откроется окно Open Maps, где можно проверить типы карт для открываемых файлов.

PixPlant попытается понять тип карты по её имени файла и автоматически выберёт тип карты. Для других записей, помеченных "Select...", вам нужно будет вручную выбрать правильный тип карты.

Ещё один способ открыть файл — вставить изображение из буфера обмена. Откройте изображение в другом приложении и скопируйте его в буфер обмена.

Вернувшись в PixPlant, выберите, в редакторе какого типа вы хотите открыть изображение, и нажмите кнопку Paste, расположенную над областью Редактора.

Вставленная карта откроется в текущем редакторе.

## 2. Инструменты для карт

### 2.1 Инструмент Delight

Инструмент Delight удаляет информацию о тенях и свете из фотографий, что особенно полезно для карты Base Color в рабочем процессе PBR, но также может помочь удалить избыточную информацию о затенении из карты Diffuse.

Инструмент Delight лучше работает с изображениями, имеющими небольшие тени, созданные собственными элементами, и не так эффективен с областями больших теней.

Для начала откройте изображение в редакторе Base Color. Чтобы увидеть Delight в действии, выберите фотографию, содержащую некоторые тени. Увеличьте ползунок Strength, переместив его вправо.

Обратите внимание, как информация о тенях и свете постепенно исчезает, заменяясь цветовой информацией. Информация о свете и затенении удаляется, оставляя на её месте цветовую информацию с определённым уровнем интенсивности или яркости. Если этот уровень не подходит, можно использовать ползунок Intensity Bias для смещения общей яркости.

Попробуйте изменить Intensity Bias, чтобы понять применяемое смещение. Области экстремальной тёмности или яркости в исходном изображении могут переполнять доступную остаточную цветовую информацию. Слабая цветовая информация также может быть утрачена в некоторых типах файлов с потерей качества из-за квантования.

Ползунок Repair пытается исправить цветовые аномалии, введённые по указанным выше причинам. Если вы заметили пятна с ненормальным цветом при осветлении, увеличьте этот ползунок, чтобы попытаться исправить эти области.

Карта теперь должна быть осветлена. Однако если исходное изображение имело очень сильные тени или блики, инструмент Delight может не восстановить цветовую информацию, и вам, возможно, потребуется вручную исправить её в инструментах Paint или даже Keying.

### 2.2 Инструмент Keying

Keying — мощный инструмент, работающий в два основных шага:

1. Выбор цвета или интенсивности из исходной направляющей карты (Guide map), чтобы создать маску.
2. С помощью этой выбранной маски применить выбранный цвет или интенсивность в целевую карту.

Являясь своего рода операцией переноса, Keying может быть полезен во многих задачах, таких как регуляризация карт, замена цвета, трассировка особенностей и многое другое.

Посмотрим, как работает Keying, попробовав его на карте. Все типы карт, кроме Normal, поддерживают Keying, поэтому откройте карту в одном из этих редакторов. Выберите направляющую карту (Guide map) из выпадающего меню, которая в нашем примере будет картой, которую вы только что открыли.

Можно использовать другое изображение или карту, открытую в другом редакторе, в качестве направляющей, что также имеет свои преимущества для переноса особенностей из одной карты в другую. Представьте, например, перенос металлической формы, содержащейся в карте Base Color, выбранной по её цвету, в карту Metallic, чтобы значения пикселей формы были установлены в 1 (полностью металлические) — таким образом вы можете переносить особенности из одной карты в другую.

После выбора Guide появятся новые элементы управления под выпадающим меню, разделённые на две секции: "Pick Mask" и "Replace With". Переместите курсор мыши над картой и нажмите в области контрастного цвета. При нажатии вы выбираете исходное значение цвета, которое будет заменено тем, что вы определите в секции "Replace With".

Маска выбранных областей в изображении Guide кратко отображается при нажатии для выбора, а также если нажать кнопку "Show Mask". Попробуйте нажать и удерживать её, чтобы увидеть маску.

Эта маска создаётся на основе соответствия цвета/значения между пикселями, контролируемого амплитудой подобия, установленной в ползунке Range: увеличение диапазона приводит к выбору большей области и наоборот.

Если изображение Guide имеет цвет, можно изменить, выполняется ли сопоставление By Color (по цвету) или By Brightness (по яркости), а также компромисс между ними. Если, например, некоторые особенности изображения более различимы по цвету, переместите ползунок в сторону By Color.

Softness управляет размытием, применяемым к границам маски. Это помогает смягчить жёсткие контуры и способствует лучшему смешиванию заменяемого цвета. Маска установлена, и нам нужно выбрать, чем её заменить. Для этого выберите значение Color/Roughness/Height: все области, ранее выбранные в маске, станут этого цвета.

Настройки Guide Mix управляют тем, насколько яркость источника Guide смешивается с плоским цветом, что очень полезно для добавления текстуры к выбранному цвету. Установка этого параметра на 0% будет использовать только плоский цвет, увеличение добавит текстуру, взятую из яркости Guide, создавая разнообразие.

Поскольку нажатие для выбора маски забудет предыдущий выбор, можно использовать кнопку "Apply and Pick Another" для фиксации текущего состояния. Или можно нажать Clear для очистки текущей маски.

При нажатии для выбора маски она применяется ко всей карте, что может быть проблематично для локальных особенностей.

Чтобы ограничить маску выбранной областью в карте, нажмите Ctrl и кликните в области редактора: это определит область выделения, которая ограничит применение маски. Добавляйте точки в область выделения (удерживая Ctrl) и, наконец, нажмите на начальную точку для замыкания — только после замыкания выделение ограничит маску.

Позже можно перетаскивать маркеры выделения для изменения области. Для очистки нажмите вне области выделения.

Для контекстной справки наведите мышь рядом с заголовком инструмента Keying: появится кнопка ( i ), на которую можно нажать для получения информации об инструменте.

### 2.3 Валидация PBR

Некоторые комбинации значений карт Base Color и Metallic могут привести к некорректному рендерингу, перестав быть физически корректными.

Правила для избежания этих проблем довольно просты:

- Для металлических участков: значения Base Color должны быть яркими.
- Для диэлектрических участков: значения Base Color не должны быть слишком яркими или слишком тёмными.

Для упрощения задачи соблюдения этих правил настройка PBR Validate доступна под областями редакторов Base Color и Metallic. Чтобы увидеть, как работает PBR Validate, создадим набор карт PBR: нажмите кнопку New Maps, расположенную над областью Редактора.

В появившемся окне New Maps в выпадающем меню Presets... в правом верхнем углу выберите пресет Silver, расположенный примерно в середине списка.

Нажмите Create для инициализации новых карт с физически точными значениями материала серебра. В 3D Preview повращайте модель, чтобы увидеть, как она отражает окружение.

Выбрав редактор Base Color, включите переключатель PBR Validate в нижней части: отобразится зелёное наложение над картой, означающее отсутствие проблем с валидацией.

Прежде чем продолжить, пожалуйста, отключите переключатель PBR Validate. Переключитесь на карту Metallic, чтобы создать диэлектрическую область в полностью металлической исходной карте.

Для этого выберите инструмент Paint Tool. Выберите его операцию Paint и установите ползунок Metallicness на 0 (означает диэлектрик) и Hardness на 100% (полная жёсткость кисти позволит избежать размытых промежуточных значений). Покрасьте нижнюю половину карты Metallic как диэлектрик.

В 3D Preview вы заметите, что в окрашенной области зеркальные характеристики серебра исчезли, и теперь она ведёт себя скорее как пластик или окрашенный металл. Это происходит потому, что теперь больше света диффундирует и меньше отражается от окрашенной области.

Теперь вернитесь в редактор Base Color. Включите PBR Validate в нижней части: теперь красным цветом наложены области, которые мы отметили как диэлектрические в карте Metallic. Это означает, что значение Base Color для этих пикселей слишком яркое и требует затемнения.

Выберите инструмент Paint и выберите его операцию Paint. Обратите внимание, что в настройках цвета появляются четыре числа: r g b (v), где последнее (v) — значение или яркость цвета. Нажмите Color и выберите серый (или цвет), значение/яркость которого меньше 240.

Теперь покрасьте область, которая отображается красным: она должна стать зелёной, что означает, что диэлектрические области теперь валидны.

Откуда взялось это значение 240? Существует два типа стандартных диапазонов валидации PBR: толерантный и строгий. Какой из них используется, можно выбрать в окне Preferences.

Но как запомнить значения в этих диапазонах? Наведите мышь на переключатель PBR Validate в нижней части: вскоре появится подсказка с допустимыми диапазонами яркости. Ещё раз проверьте, что значение цвета/яркости, которое вы только что выбрали, находится в допустимом диапазоне для диэлектриков.

Теперь покрасим цвет, слишком тёмный для металлической области, что является недопустимым.

В палитре цвета инструмента Paint выберите цвет со значением/яркостью ниже 153 и покрасьте в средней половине карты Base Color. По мере рисования появится красное наложение над новыми мазками, означающее, что значение/яркость цвета недопустимо для металлической области.

Чтобы исправить это, выберите более яркий цвет (проверьте допустимый диапазон в подсказке переключателя PBR Validate) и покрасьте поверх. Можно рисовать с включённым или выключенным наложением PBR Validate.

Когда в наложении PBR Validate больше не видно красных областей, это означает, что карты Base Color и Metallic валидны и могут использоваться без опасений.

### 2.4 Инструмент Transform

Инструмент Transform может вращать, обрезать, изменять размер, деформировать, корректировать перспективу или зацикливать одну или несколько карт одновременно. Общие операции, такие как выравнивание или выпрямление исходного фото, можно легко выполнить с помощью этого инструмента.

Начните с открытия карты (File Open, Paste, Drag'n'Drop...) в одном из редакторов. При выборе инструмента Transform переключатель Tiling Preview в нижней части области Редактора включается, повторяя изображение по краям для лучшей визуализации его тайлинга.

Обратите внимание на четыре маркера в углах изображения, соединённые чёрными и белыми линиями вдоль сторон изображения.

Эти маркеры и линии показывают положение исходного прямоугольника изображения и позволяют выполнять операции трансформации путём их перетаскивания, с нажатой или без нажатой клавишей Ctrl.

Переключатель "This Map - All Maps" управляет тем, применяются ли изменения только к текущей карте или ко всем открытым картам. Нажмите и перетащите один из угловых маркеров: изображение будет вращаться вокруг своего центра.

Теперь перед перетаскиванием угла нажмите Ctrl: изображение будет деформировано или скорректировано по перспективе в зависимости от положений маркеров и выравнивания между чёрными и белыми линиями.

В области управления инструментом настройка Outside Fill определяет, что происходит с пикселями, которые будут трансформированы из-за пределов исходного изображения и, следовательно, будут неопределёнными. Например, что происходит с неопределёнными пикселями при вращении изображения? В этой настройке можно установить, следует ли им зацикливаться как обычно (Tiling), выполнять зеркальное зацикливание (Mirrored Tiling) или прижиматься к краям (Edge Clamp).

Попробуйте нажать и перетащить чёрно-белую линию, соединяющую два маркера: изображение изменит размер пропорционально относительно противоположной стороны. Если изменить размер на меньший, чем исходный размер изображения, оно будет зацикливать копии самого себя в соответствии с выбором Outside Fill.

Но если перетащить чёрно-белую линию, удерживая Ctrl, переместится только перетаскиваемая сторона, тем самым изменяя размер непропорциональным образом.

Вернёмся к элементам управления инструментом: переключатель Show Grid включает отображение сетки, которая может быть полезна для выравнивания краёв. Перетаскивание центра выделения перемещает изображение. Попробуйте перетащить его, чтобы увидеть, что произойдёт.

Кнопка Reset Controls вернёт управляющие маркеры в исходные положения по углам и сбросит трансформацию. В нижней части инструмента вы найдёте настройки Final Size, управляющие эффективным размером карты после применения всех трансформаций. Ссылка Reset возвращает финальный размер к предыдущим значениям карты.

Используя эту и другие рассмотренные операции, можно выполнять множество типов выравнивания и обрезки с помощью инструмента Transform.

## 3. Извлечение карт

### 3.1 Извлечение карт

Часто бывает полезно извлечь карту из изображения или из другой исходной карты. Все карты можно извлечь, за исключением карты Base Color, которая обычно является источником для извлечения других карт.

В некоторых случаях извлечение довольно точно и похоже на вычисление, например при извлечении Ambient Occlusion из карты Displacement. В других случаях это скорее приближение, предоставляющее отправную точку, для которой требуется дальнейшая настройка.

Начнём с выбора редактора, в который вы хотите извлечь карту, из вкладок карт над Редактором. Для извлечения карты можно использовать инструмент Extract, доступный в верхней части инструментов Map Tools для текущей карты.

Большинство карт можно извлечь из различных типов источников, поэтому первым шагом является выбор метода извлечения. Другие карты, например Metallic, можно извлекать только из фиксированной карты, обычно Base Color. Если это так, настройки Method не будет, просто перейдите к следующему шагу.

Теперь выберите фактическое исходное изображение, нажав на выпадающее меню Source. Доступные опции зависят от того, что было выбрано в настройке Method, и включают:

- Использовать открытую в данный момент карту.
- Открыть из файла на вашем компьютере.
- Вставить изображение из буфера обмена.
- Перетащить файл в область инструмента (не в Редактор).

После выбора исходного изображения извлечение начнётся автоматически.

Извлечённое изображение будет иметь ту же ширину и высоту, что и исходное. Если по случайности в целевом редакторе открыта карта другого размера, появится окно с вопросом, какой размер сохранить.

После начала извлечения новые настройки могут появиться сразу под настройкой Source, позволяя настроить извлечённую карту. Эти настройки зависят от того, какую карту вы извлекаете: пожалуйста, проверьте информацию об инструменте, наведя мышь на заголовок инструмента Extract и нажав появившуюся кнопку ( i ).

Извлечённая карта может потребовать дальнейшей доработки или ретуши с помощью других доступных инструментов, таких как Keying или Paint.

### 3.2 Извлечение карты смещения

Мы будем использовать инструмент Extract для генерации карты смещения из информации о затенении на фотографии или из нормалей в карте нормалей.

Если открыта предыдущая карта Displacement, она закроется, чтобы мы могли начать.

Откройте инструмент Extract в области Map Tools справа, если он ещё не открыт. Начните с выбора метода, который может быть одним из:

- Из информации о затенении на фотографии.
- Из нормалей в файле карты нормалей.

В зависимости от того, какую карту вы планируете использовать в качестве источника, выберите один из этих двух вариантов. Теперь выберите фактическое исходное изображение, нажав на выпадающее меню Source.

Вы можете выбрать:

- Использовать открытую в данный момент карту Base Color или Normal.
- Открыть из файла на вашем компьютере.
- Вставить изображение из буфера обмена.
- Перетащить файл в область инструмента (не в Редактор).

После выбора исходного изображения извлечение начнётся автоматически.

Извлечённое изображение будет иметь ту же ширину и высоту, что и исходное. Если по случайности открыта карта Displacement другого размера, появится окно с вопросом, какой размер сохранить.

После начала извлечения появятся новые настройки, позволяющие настроить извлечённую поверхность смещения.

Используйте ползунок Surface для управления рельефом поверхности. Более низкие значения извлекают более гладкие карты с крупными элементами, но с малым количеством мелких деталей, тогда как более высокие значения извлекают более чёткое смещение. Попробуйте перемещать этот ползунок для настройки извлечённой поверхности. (Эта настройка недоступна при извлечении из нормалей)

Ползунок Detail добавляет мелкие детали к извлечённой поверхности. Крайнее левое положение ничего не добавляет, более высокие значения постепенно добавляют мелкие и даже средние по уровню детали.

Ползунок Range позволяет управлять тем, насколько далеко друг от друга находятся верхние и нижние точки поверхности.

Извлечённое смещение может быть дополнительно доработано или отретушировано с помощью других доступных инструментов, таких как Keying или Paint.

Чтобы лучше понять извлечённую карту смещения, можно переключать Редактор между 2D- и 3D-видами, нажимая кнопку в левом верхнем углу Редактора.

Масштабируйте карту смещения вращением колёсика мыши. Также можно перетаскивать изображение, удерживая правую кнопку мыши, для вращения. Удерживая среднюю кнопку мыши, можно перемещать карту смещения по экрану.

### 3.3 Извлечение карт АО

Инструмент Extract вычисляет рендеринг карты окружения (Ambient Occlusion, AO) из карты Displacement или Normal.

Если открыта предыдущая карта AO, она закроется, чтобы мы могли начать.

Откройте инструмент Extract в области Map Tools справа, если он ещё не открыт. В зависимости от вашего источника выберите, какой метод использовать:

- Из информации о смещениях.
- Из нормалей в файле карты нормалей.

Этот выбор повлияет на то, что появится в выпадающем меню Source сразу ниже. Теперь выберите фактическую исходную карту, нажав на выпадающее меню Source.

Вы можете выбрать:

- Использовать открытую в данный момент карту.
- Открыть из файла на вашем компьютере.
- Вставить изображение из буфера обмена.
- Перетащить файл в область инструмента (не в Редактор).

После выбора исходного изображения вычисление AO начнётся автоматически.

Извлечённое изображение будет иметь ту же ширину и высоту, что и исходное. Если по случайности уже открыта карта АО другого размера, появится окно с вопросом, какой размер сохранить.

После начала вычисления АО появится новый ползунок, позволяющий настроить результат.

Используйте ползунок Ray Distance для управления расстоянием в пикселях, на которое окружение может влиять на точку в изображении. Меньшие расстояния приводят к более гладким картам АО, так как меньше шансов на затенение на коротких расстояниях. Но для получения хорошего затенения крупных элементов потребуется увеличить Ray Distance.

Попробуйте разные расстояния лучей, чтобы увидеть этот вид "настройки особенностей" в действии.

При необходимости извлечённое смещение может быть дополнительно доработано или отретушировано с помощью других доступных инструментов, таких как Adjust или даже Paint.
