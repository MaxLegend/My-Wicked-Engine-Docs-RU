Таблица основных символов разметки Markdown с их значениями:

| **Символ(ы)** | **Значение / Назначение** |
|---------------|----------------------------|
| `#`           | Заголовок 1-го уровня (`# Заголовок`) |
| `##`          | Заголовок 2-го уровня |
| `###`         | Заголовок 3-го уровня |
| `####`        | Заголовок 4-го уровня |
| `#####`       | Заголовок 5-го уровня |
| `######`      | Заголовок 6-го уровня |
| `*текст*`     | Курсив (альтернатива: `_текст_`) |
| `**текст**`   | Полужирный (альтернатива: `__текст__`) |
| `***текст***` | Полужирный курсив (или `___текст___`) |
| `` `текст` `` | Инлайн-код (моноширинный шрифт) |
| ``` ```<br>```код```<br>``` | Блок кода (многострочный) |
| `-` или `*` или `+` | Маркированный список (в начале строки с отступом) |
| `1.`          | Нумерованный список |
| `>`           | Цитата (blockquote) |
| `[текст](ссылка)` | Ссылка |
| `![описание](путь/к/изображению)` | Изображение |
| `---` или `***` или `___` | Горизонтальная линия (разделитель) |
| `\`           | Экранирование специальных символов (например, `\*` покажет звёздочку как текст) |
| `|`           | Разделитель колонок в таблице |
| `:-` или `:-:` или `-:` | Выравнивание в таблицах (лево, центр, право) |
| `~~текст~~`   | Зачёркнутый текст (в расширенном Markdown, например, в GitHub Flavored Markdown) |
